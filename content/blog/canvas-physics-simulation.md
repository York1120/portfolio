物理互动实验的核心是物理模拟引擎。在浏览器环境中，HTML5 Canvas 提供了足够的性能和灵活性来实现大多数初中物理实验的模拟。

## 技术架构

每个互动实验的基本架构分为三层：

- **物理引擎层** — 负责计算物理规律，如牛顿运动定律、光学折射公式、电路欧姆定律等。
- **渲染层** — 使用 Canvas 2D API 将物理状态绘制到屏幕上。
- **交互层** — 处理鼠标拖拽、滑块调节、按钮点击等用户交互。

## 关键技术点

几个值得分享的实现技巧：

- **requestAnimationFrame 循环** — 使用浏览器原生的动画帧驱动物理更新，保证 60fps 的流畅体验。
- **时间步长固定** — 物理更新使用固定的时间步长（如 1/60 秒），避免帧率波动导致物理行为不一致。
- **交互状态管理** — 使用状态机管理拖拽、放置、动画播放等交互状态，避免状态混乱。

## 性能优化

对于粒子系统（如分子热运动模拟），使用对象池模式复用粒子对象，避免频繁的垃圾回收导致卡顿。对于光路渲染，使用离屏 Canvas 预计算复杂光路，再绘制到主 Canvas 上。
