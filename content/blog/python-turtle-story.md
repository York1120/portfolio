title: 用 turtle 模块上了一节美术课
date: 2026-06-10
category: 课程设计
excerpt: 信息技术课和美术课的跨界合作，意外地成了这学期最受欢迎的一节课。
---

事情是这样的。美术老师有天在办公室抱怨，说这周要上"色彩构成"的课，但学生总是分不清 RGB 和 CMYK 的区别。我随口接了一句："那我用 Python turtle 给你画个 RGB 色轮？"她眼睛一亮："真的？那干脆咱俩合上一节课？"

于是就有了这节跨界课。前半节美术老师讲色彩理论，后半节我带学生用 turtle 模块把理论变成代码。我写了一个示例程序，用循环和颜色渐变画了一个 RGB 色轮，然后让学生自己修改参数，观察颜色变化。

课堂气氛好得出乎意料。平时上信息技术课不太爱动手的几个女生，这节课特别投入，因为她们觉得"这是在画画不是在编程"。有个女生调出了一组渐变色，兴奋地喊："老师你看，这个颜色和我的笔袋一模一样！"

这节合作课让我意识到，编程教育不一定非得是孤立的。和其他学科结合起来，学生更容易看到编程的实用价值，学起来也更有动力。我已经在琢磨下次和数学老师合作上一节"用 Python 画函数图像"了。
